
# Blinkit UI Clone 🛒

A clean and responsive **UI clone of Blinkit** (formerly Grofers), developed using **HTML**, **CSS**, and **Bootstrap**. This project captures the design and layout of the Blinkit home interface for design practice and portfolio showcasing.

---

## 🎯 Purpose

Created to demonstrate **frontend UI/UX design skills** by replicating an industry-standard grocery delivery platform's interface using only web fundamentals.

---

## 🖼️ Features

- Header with logo and location dropdown
- Search bar for products
- Categories grid (Fruits, Beverages, Snacks, etc.)
- Promotional sliders/banners
- Product cards with pricing and add-to-cart buttons
- Footer with informational links

---

## 🧰 Technologies Used

- HTML5
- CSS3
- Bootstrap 5

---

## 📱 Responsiveness

Responsive design ensured via Bootstrap:
- Mobile, tablet, and desktop-friendly
- Fluid grid layouts and stackable components
- Adaptive typography and spacing

---

## 🚀 How to Run

1. Clone the repository:
```bash
git clone https://github.com/AmanTiwari83/blinkit-ui-clone.git
```

2. Open `index.html` in any web browser.
